隐私政策

最后更新时间：2026 年 9 月 23 日

Naro 将 Mac 上的 Office 文件连接到 Google 编辑器。本页介绍了该应用程序访问的内容、其去向以及如何将其删除。

谁提供Naro

Naro 是由 Sergei Sakharovskii 开发的独立应用程序（@plexideas）。本政策涵盖 Naro macOS 应用程序和此信息网站。

Google 帐户信息

当您登录时，Naro 会请求您的 Google 帐户标识符、电子邮件地址、姓名和个人资料图片，以显示您连接的帐户并让您选择正确的帐户。授权发生在您的浏览器中； Naro 没有收到您的 Google 密码。

Naro请求 openid, email, profile，和 https://www.googleapis.com/auth/drive.file。驱动器权限允许访问 Naro 创建的或明确提供给 Naro 的文件。 Naro 不会请求读取您的整个 Google 云端硬盘的权限。

文件与同步

当您使用 Naro 打开文件并选择帐户时，应用程序会将该文件及其文件名直接上传到您的 Google 云端硬盘。浏览器打开Google相应的编辑器。当 Naro 在线运行时，它会检查链接文件的更改并将保存的更新下载到您的 Mac。

Google 接收提供这些服务所需的文档内容和帐户相关请求。谷歌根据自己的方式处理这些数据 隐私政策 和您的帐户设置。 Naro 不会将文档发送到开发人员操作的后端。

Mac 上存储的信息

  • 登录令牌和连接的帐户详细信息存储在 macOS 钥匙串中。
  • 本地文档路径和书签、Google 文件标识符、帐户关联、同步元数据和打开历史记录存储在 ~/Library/Application Support/Naro/.
  • 在覆盖本地文档之前，Naro 会保留备份。冲突的版本将被保留。备份不会自动删除。
  • 个人资料照片是从 Google 获取的。 macOS 可能会在本地缓存图像响应。

信息的使用方式

Naro 使用 Google 帐户和文档数据来提供登录、帐户选择、文件打开、同步、最近文档历史记录和恢复副本。当前的应用程序不包含广告、分析 SDK 或开发人员运营的遥测服务。 Naro 不会出售这些数据或使用文档内容来训练 AI 模型。

Naro 对从 Google API 收到的信息的使用和传输到任何其他应用程序均遵守 Google API 服务用户数据政策，包括其限制使用要求。

断开连接并删除数据

在 Naro 中删除帐户会删除其本地保存的授权并停止该帐户的同步。它不会删除您的本地文档、备份、打开历史记录或 Google 云端硬盘中的文件。

要撤销 Google 的授权，请将 Naro 从 您的 Google 帐户的第三方连接。要删除本地历史记录和备份，请退出 Naro 并在保存所需的任何备份后删除其应用程序支持文件夹。仅删除该文件夹不会从钥匙串中删除登录令牌；首先断开 Naro 中的帐户。如果您不想再保留上传的文件，请在 Google 云端硬盘中单独删除它们。本地支持数据将保留，直至您将其删除。

应用程序更新

Naro 默认检查 GitHub 版本是否有新版本。您可以在应用程序中禁用自动检查。检查更新或下载版本会将技术连接信息（例如您的 IP 地址）发送到 GitHub。这些请求不包括您的 Google 令牌或文档。仅当您选择更新时才会进行安装和重新启动。

这个网站

网站根据您的浏览器设置选择语言。如果您选择其他语言，网站只会将此语言偏好保存在浏览器的本地存储中。

该网站托管在 Netlify 上并通过 Cloudflare 交付。网站代码不添加分析、广告、跟踪脚本或 cookie。托管和交付提供商可能会处理技术访问信息（包括 IP 地址），以操作和保护网站，如 Cloudflare 隐私政策 和 Netlify 隐私政策。存储库和支持链接打开 GitHub，其对该活动的处理在 GitHub 隐私声明。打开其他外部链接会将您带到相应提供商的服务。

问题和变更

对于一般隐私问题，请通过以下方式联系维护者 Naro 存储库。问题是公开的：请勿发布文档、密码、令牌或私人帐户详细信息。当应用程序的数据处理发生变化时，本政策将会更新；上面的日期标识的是最新版本。
