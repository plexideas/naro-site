使用 Naro

使用条款

最后更新时间：2026 年 9 月 23 日

Naro 是一款由 Sergei Sakharovskii 开发的独立 macOS 应用程序。公共安装程序可通过 GitHub 发布.

Naro做什么

Naro 在 Google 基于浏览器的编辑器中打开受支持的 Office 文件，并将保存的更改同步回您的 Mac。您需要兼容的 Mac、互联网连接以及有权使用相关服务的 Google 帐户。您的组织可能会限制对第三方应用程序的访问。

您的文件和帐户

仅连接帐户并打开您有权使用的文件。您保留文档的所有权。使用 Naro 并不授予开发者对您的内容的所有权。该应用程序的数据处理在 隐私政策.

实际限制

Naro 可能包含缺陷或在版本之间改变行为。保留重要文件的独立备份。同步需要 Naro 保持运行，并取决于 Google 保存文件和网络可用性。 Office 兼容性取决于 Google 的编辑器；复杂的文档功能可能会发生变化或不受支持。

关闭 Naro 会停止同步，直到它再次运行。删除本地文件不会自动删除 Google 云端硬盘副本，删除云端硬盘副本也不会删除您的本地文档。 Naro 可以在 GitHub 上检查更新；下载、安装和重新启动需要您在应用程序中执行操作。

第三方服务和名称

Google 服务和 GitHub 根据其自己的条款和隐私政策提供。 Naro 不隶属于 Google、Microsoft 或 Apple，也不受其认可。他们的名称和商标属于其各自所有者。

项目材料

此公共存储库包含信息网站和文档。它不包含 macOS 应用程序源，也不授予重新分发应用程序的许可证。发布本网站并未为该应用程序授予开源许可证。

联系方式

联系维护者 Naro 的 GitHub 问题 对于一般问题和反馈。不要在公共问题中包含私人文件或凭证。
