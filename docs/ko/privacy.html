귀하의 데이터에 대한 설명

개인정보 보호정책

최종 업데이트: 2026년 9월 24일

Naro는 Mac의 Office 파일을 Google 편집기에 연결합니다. 이 페이지에서는 앱이 액세스하는 항목, 이동 위치, 제거 방법을 설명합니다.

Naro를 제공하는 사람

Naro는 Sergei Sakharovskii(@plexideas). 이 정책은 Naro macOS 앱과 이 정보 웹사이트에 적용됩니다.

Google 계정 정보

로그인하면 Naro는 연결된 계정을 표시하고 올바른 계정을 선택할 수 있도록 Google 계정 식별자, 이메일 주소, 이름 및 프로필 사진을 요청합니다. 승인은 브라우저에서 이루어집니다. Naro는 귀하의 Google 비밀번호를 수신하지 않습니다.

Naro의 부탁 openid, email, profile그리고 https://www.googleapis.com/auth/drive.file. 드라이브 권한은 Naro에서 생성되었거나 명시적으로 사용 가능한 파일에 대한 액세스를 허용합니다. Naro는 Google 드라이브 전체를 읽을 수 있는 권한을 요청하지 않습니다.

문서 및 동기화

Naro로 파일을 열고 계정을 선택하면 앱이 해당 파일과 파일 이름을 Google 드라이브에 직접 업로드합니다. 브라우저는 Google의 해당 편집기를 엽니다. Naro가 실행 중이고 온라인인 동안 연결된 파일의 변경 사항을 확인하고 저장된 업데이트를 Mac에 다운로드합니다.

Google은 이러한 서비스를 제공하는 데 필요한 문서 콘텐츠 및 계정 관련 요청을 받습니다. Google은 자체 규정에 따라 해당 데이터를 처리합니다. 개인정보 보호정책 및 계정 설정. Naro는 개발자가 운영하는 백엔드로 문서를 보내지 않습니다.

Mac에 저장된 정보

  • 로그인 토큰 및 연결된 계정 세부정보는 macOS 키체인에 저장됩니다.
  • 로컬 문서 경로 및 북마크, Google 파일 식별자, 계정 연결, 동기화 메타데이터 및 열기 기록은 다음 위치에 저장됩니다. ~/Library/Application Support/Naro/.
  • Naro는 로컬 문서를 덮어쓰기 전에 백업을 보관합니다. 충돌하는 버전은 보존됩니다. 백업은 자동으로 삭제되지 않습니다.
  • 프로필 사진은 Google에서 가져옵니다. macOS는 이미지 응답을 로컬로 캐시할 수 있습니다.

정보가 사용되는 방식

Naro는 로그인, 계정 선택, 파일 열기, 동기화, 최근 문서 기록, 복구 사본 제공을 위해 Google 계정 및 문서 데이터를 사용합니다. 현재 앱에는 광고, 분석 SDK 또는 개발자가 운영하는 원격 측정 서비스가 포함되어 있지 않습니다. Naro는 AI 모델을 훈련하기 위해 이 데이터를 판매하거나 문서 콘텐츠를 사용하지 않습니다.

Naro가 Google API에서 받은 정보를 사용하고 다른 앱으로 전송하는 행위는 다음을 준수합니다. Google API 서비스 사용자 데이터 정책, 제한된 사용 요구 사항 포함.

데이터 연결 끊기 및 삭제 중

Naro에서 계정을 제거하면 로컬에 저장된 인증이 삭제되고 해당 계정에 대한 동기화가 중지됩니다. 로컬 문서, 백업, 열기 기록 또는 Google 드라이브의 파일은 삭제되지 않습니다.

Google의 승인을 취소하려면 다음에서 Naro를 삭제하세요. Google 계정의 제3자 연결. 로컬 기록과 백업을 제거하려면 Naro를 종료하고 필요한 백업을 저장한 후 Application Support 폴더를 삭제하세요. 해당 폴더만 제거해도 키체인에서 로그인 토큰은 제거되지 않습니다. 먼저 Naro에서 계정을 연결 해제하세요. 업로드된 파일을 더 이상 보관하지 않으려면 Google 드라이브에서 별도로 삭제하세요. 로컬 지원 데이터는 삭제할 때까지 유지됩니다.

애플리케이션 업데이트

Naro는 기본적으로 GitHub 릴리스에서 새 버전을 확인합니다. 앱에서 자동 검사를 비활성화할 수 있습니다. 업데이트를 확인하거나 릴리스를 다운로드하면 IP 주소와 같은 기술 연결 정보가 GitHub로 전송됩니다. 이러한 요청에는 Google 토큰이나 문서가 포함되지 않습니다. 업데이트를 선택한 경우에만 설치 및 다시 시작이 수행됩니다.

이 웹사이트

브라우저 설정에 따라 언어가 자동으로 선택됩니다. 다른 언어를 선택하면 웹사이트는 해당 언어 설정만 브라우저의 로컬 저장소에 저장합니다.

이 웹사이트는 Netlify에서 호스팅되며 Cloudflare를 통해 제공됩니다. 이들 제공업체는 사이트 운영과 보호를 위해 IP 주소를 포함한 기술적 접속 정보를 처리할 수 있습니다. 자세한 내용은 다음 정책을 확인하세요: Cloudflare 개인정보 보호정책 그리고 넷리파이 개인정보 보호정책. 리포지토리 및 지원 링크는 GitHub를 엽니다. 해당 활동 처리는 GitHub 개인정보 보호정책. 다른 외부 링크를 열면 해당 제공업체의 서비스로 이동됩니다.

Netlify를 사용해 일별 방문자와 다운로드 링크 클릭 수를 집계합니다. IP 주소와 브라우저 정보를 매일 바뀌는 임의의 솔트로 해시하여 반복 방문을 묶으며, 분석 데이터베이스에는 원래 IP 주소나 브라우저 정보를 저장하지 않습니다. 분석에는 쿠키나 브라우저 저장소를 사용하지 않습니다. 이벤트는 30일, 일별 솔트는 최대 2일 보관합니다. 집계된 수치만 표시합니다. 클릭은 다운로드 완료나 설치를 확인하지 않습니다.

질문 및 변경사항

일반적인 개인 정보 보호 관련 질문은 다음을 통해 관리자에게 문의하세요. Naro 저장소. 문제는 공개되어 있습니다. 문서, 비밀번호, 토큰 또는 개인 계정 세부정보를 게시하지 마세요. 이 정책은 앱의 데이터 처리가 변경되면 업데이트됩니다. 위의 날짜는 최신 버전을 나타냅니다.
