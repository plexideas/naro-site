Naro 사용 가이드

간단한 가이드.
편리한 시작.

Naro와 함께 집처럼 편안함을 느낄 수 있는 몇 가지 실용적인 단계입니다.

macOS 26+ 및 Apple Silicon의 Naro용. GitHub 릴리스에서 사용 가능합니다.

시작하기

첫 번째 파일,
처음부터 끝까지.

Naro가 연결되면 더블클릭만 하면 됩니다.

  1. Naro를 열고 Google을 연결하세요.

    응용 프로그램 폴더에서 Naro를 시작하세요. Google 로그인 버튼을 선택하세요. 브라우저가 열리면 계정을 선택하고 요청된 액세스 권한을 부여할 수 있습니다. 로그인이 완료되면 Naro로 돌아갑니다.

  2. Naro를 기본으로 설정하세요.

    툴바의 계정 아이콘을 사용해 계정 화면을 엽니다. 찾기 Finder에서 열기 를 선택하고 구성…그런 다음 시스템의 기본 애플리케이션 선택을 확인하세요.

    Naro 메뉴 → 언어에서 언어를 선택하세요. 시스템 언어를 일치시키려면 “Follow macOS”를 사용하세요.

  3. 오피스 문서를 더블클릭하세요.

    Finder에서 DOC/DOCX, XLS/XLSX, PPT/PPTX 파일을 엽니다. 두 개 이상의 계정을 연결한 경우 아바타 선택기에서 하나를 선택하세요. Naro는 해당 계정의 Google 드라이브에 파일을 업로드하고 해당 편집기를 엽니다.

  4. 브라우저에서 편집하세요.

    변경하고 Google에서 저장하도록 하세요. 저장된 변경 사항이 로컬 파일로 돌아갈 수 있도록 Naro를 실행하고 Mac을 온라인 상태로 유지하세요. Closing Naro’s window is fine; 앱을 종료하면 동기화가 일시 중지됩니다.

Keep an eye on compatibility.

Files up to 100 MB are supported. 복잡한 Office 형식, 매크로, 고급 기능은 Google 편집자가 지원하는 기능에 따라 다릅니다.

Google 계정

The right account
모든 파일에 대해.

선택한 계정으로 업무 및 개인 문서를 보관하세요.

WP

  1. Add another account.

    Naro를 열고 계정 화면으로 이동하여 + 버튼. 추가하려는 계정으로 브라우저에서 Google 로그인을 완료하세요. 기존 계정에 로그인하면 중복 계정을 추가하는 대신 승인이 업데이트됩니다.

  2. Choose an avatar when opening a file.

    하나의 계정으로 Naro가 직접 파일을 엽니다. 여러 개의 경우 작은 계정 선택기가 먼저 나타납니다. 아바타 위에 마우스를 올려 계정 이름과 이메일을 확인한 후 선택하세요.

  3. Cancel without uploading.

    취소하려면 Esc 키를 누르거나 선택기 외부를 클릭하세요. Naro는 계정이 선택될 때까지 파일을 업로드하지 않습니다.

  4. Remove an account when you need to.

    계정 화면에서 계정 옆에 있는 제거 컨트롤을 사용하세요. Naro는 이 Mac에 저장된 로그인을 지우고 해당 계정의 동기화를 중지합니다. 로컬 문서, 기록, 백업, Google 드라이브 파일은 그대로 유지됩니다.

연결해제와 접근권한 철회는 다릅니다.

Google의 승인도 취소하려면 다음에서 Naro를 삭제하세요. Google 계정의 제3자 연결. 참조 개인정보 보호정책 for deletion details.

저장 및 동기화

Keep your changes
집에 갑니다.

무엇이 저장되는지, 두 개의 사본이 변경되면 어떤 일이 일어나는지 알아보세요.

⇄

  1. Google에 저장할 시간을 주세요.

    Naro가 실행 중이고 인터넷에 연결되어 있으면 연결된 파일의 변경 사항을 확인합니다. Google에서 저장을 마쳐야 업데이트를 다운로드할 수 있습니다. 저장 시간은 네트워크와 파일 크기에도 영향을 받으며 즉시 완료되지는 않습니다.

  2. Naro를 실행시켜주세요.

    Naro창을 닫고 계속 작업하시면 됩니다. 메뉴 표시줄 아이콘이 없습니다. 최근 파일을 보려면 앱을 다시 여세요. Naro를 종료한 경우 다시 열어 동기화를 재개하세요.

  3. 두 사본이 모두 변경된 경우 버전을 선택하세요.

    파일이 로컬 및 Google에서 변경되면 Naro는 두 버전을 모두 보존하고 어느 버전을 계속할 것인지 묻습니다. Google 버전, 로컬 버전을 선택하거나 나중에 결정하세요. Naro는 로컬 문서를 덮어쓰기 전에 백업도 생성합니다.

  4. 원본 파일 링크를 유지하세요.

    Google이 이전 DOC, XLS 또는 PPT 파일을 업그레이드하는 경우 Naro는 원본과 함께 최신 형식의 사본을 저장합니다. Google의 별도 "Google Docs/Sheets/Slides로 저장" 변환을 사용하면 원본 Naro 링크가 추적하지 않는 또 다른 문서가 생성됩니다.

백업은 Mac에 유지됩니다.

아래에 저장되어 있습니다. ~/Library/Application Support/Naro/Backups/ 자동으로 삭제되지 않습니다. 로컬 문서를 삭제해도 드라이브 사본은 삭제되지 않으며, 드라이브 사본을 삭제해도 로컬 문서는 삭제되지 않습니다.

아직도 질문이 있으신가요?

무엇을 하려고 했는지 알려주세요. 개인 파일과 계정 자격 증명을 공개 문제에 노출되지 않도록 보관하세요.
