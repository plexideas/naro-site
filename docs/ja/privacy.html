プライバシーポリシー

最終更新日: 2026 年 9 月 23 日

Naro は、Mac 上の Office ファイルを Google のエディターに接続します。このページでは、アプリが何にアクセスし、どこに行くか、そしてアプリを削除する方法について説明します。

Naroの提供者

Naro は Sergei Sakharovskii (@plexideas)。このポリシーは、Naro macOS アプリとこの情報 Web サイトを対象としています。

Googleアカウント情報

サインインすると、Naro は Google アカウント ID、電子メール アドレス、名前、プロフィール写真を要求して、接続されているアカウントを表示し、正しいアカウントを選択できるようにします。認証はブラウザで行われます。 Naro は Google パスワードを受け取りません。

Naro が要求する権限は openid, email, profile、および https://www.googleapis.com/auth/drive.file。ドライブ権限により、Naro によって作成されたファイル、または明示的に Naro が利用できるようになったファイルへのアクセスが許可されます。 Naro は、Google ドライブ全体を読み取る許可を要求しません。

ドキュメントと同期

Naro でファイルを開いてアカウントを選択すると、アプリはそのファイルとそのファイル名を Google ドライブに直接アップロードします。ブラウザにより、Google の対応するエディタが開きます。 Naro が実行されオンラインになっている間、リンクされたファイルに変更がないかチェックし、保存された更新を Mac にダウンロードします。

Google は、これらのサービスを提供するために必要なドキュメントのコンテンツとアカウント関連のリクエストを受け取ります。 Google はそのデータを独自の方法で処理します プライバシー ポリシー とアカウント設定。 Naro は、開発者が運営するバックエンドにドキュメントを送信しません。

Mac に保存されている情報

  • サインイン トークンと接続されたアカウントの詳細は macOS キーチェーンに保存されます。
  • ローカルドキュメントのパスとブックマーク、Google ファイル識別子、アカウントの関連付け、同期メタデータ、および開いた履歴は、次の場所に保存されます。 ~/Library/Application Support/Naro/.
  • ローカルドキュメントを上書きする前に、Naro はバックアップを保持します。競合するバージョンは保存されます。バックアップは自動的には削除されません。
  • プロフィール写真は Google から取得されます。 macOS は画像応答をローカルにキャッシュする場合があります。

情報の使用方法

Naro は、Google アカウントとドキュメント データを使用して、サインイン、アカウントの選択、ファイルを開く、同期、最近のドキュメント履歴、リカバリ コピーを提供します。現在のアプリには、広告、分析 SDK、開発者が運営するテレメトリ サービスは含まれていません。 Naro は、このデータを販売したり、AI モデルをトレーニングするためにドキュメント コンテンツを使用したりしません。

Naro による Google API から受信した情報の使用および他のアプリへの転送は、 Google API サービスのユーザー データ ポリシー、限定使用要件を含む。

切断とデータの削除

Naro でアカウントを削除すると、ローカルに保存された認証が削除され、そのアカウントの同期が停止します。ローカルのドキュメント、バックアップ、開いた履歴、Google ドライブ内のファイルは削除されません。

Google の承認を取り消すには、Naro をから削除してください Google アカウントのサードパーティ接続。ローカル履歴とバックアップを削除するには、Naro を終了し、必要なバックアップを保存した後、Application Support フォルダーを削除します。そのフォルダーだけを削除しても、キーチェーンからサインイン トークンは削除されません。まずNaroのアカウントを切断してください。アップロードしたファイルを保存したくない場合は、Google ドライブに個別に削除してください。ローカル サポート データは削除するまで残ります。

アプリケーションのアップデート

Naro は、デフォルトで GitHub リリースで新しいバージョンをチェックします。アプリで自動チェックを無効にすることができます。アップデートの確認やリリースのダウンロードを行うと、IP アドレスなどの技術的な接続情報が GitHub に送信されます。これらのリクエストには、Google トークンやドキュメントは含まれません。インストールと再起動は、更新を選択した場合にのみ行われます。

このウェブサイト

この Web サイトは Netlify でホストされ、Cloudflare を通じて配信されます。 Web サイトのコードには、分析、広告、追跡スクリプト、または Cookie は追加されません。ホスティングプロバイダーおよび配信プロバイダーは、Web サイトの運用とセキュリティを確保するために、IP アドレスを含む技術的なアクセス情報を処理する場合があります。 Cloudflareプライバシーポリシー そして Netlify プライバシー ポリシー。リポジトリとサポートのリンクは GitHub を開きます。そのアクティビティの処理については、「 GitHub のプライバシーに関する声明。他の外部リンクを開くと、対応するプロバイダーのサービスに移動します。
