# Публикация Naro в Netlify

Репозиторий сайта: **https://github.com/plexideas/naro-site**.

Действующий проект Netlify: **naro-app**, домен **naro.tools**. Страницы статические; для статистики используются Netlify Functions и Blobs. Зависимости и проверки запускаются автоматически. Google OAuth-секреты не нужны.

## Подключение GitHub

1. В Netlify выберите добавление нового проекта и импорт существующего репозитория (**Import an existing project**).
2. Подключите GitHub и разрешите Netlify доступ к репозиторию **plexideas/naro-site**.
3. Выберите ветку **main**.
4. Проверьте настройки:

   | Поле                  | Значение        |
   | --------------------- | --------------- |
   | Base directory        | Оставить пустым |
   | Build command         | Из `netlify.toml` |
   | Publish directory     | `docs`          |
   | Environment variables | Не нужны        |

5. Запустите публикацию. Папка `docs` уже указана в `netlify.toml`, Netlify должен подхватить её автоматически.
6. Откройте выданный Netlify адрес и проверьте главную страницу, ссылки **Privacy** и **Terms**, а также изображения.

При подключённой автоматической публикации изменения в ветке `main` будут появляться на сайте после успешного развёртывания Netlify.

## Свой домен

В настройках проекта Netlify добавьте свой домен и внесите DNS-записи, которые покажет Netlify. Дождитесь подключения домена и выпуска HTTPS-сертификата. Конкретные записи зависят от домена и текущего DNS-провайдера.

После подключения сообщите итоговый адрес: его нужно добавить в метаданные сайта и описание репозитория. Внутренние ссылки уже относительные, поэтому сайт работает без переделки под конкретный домен.

## Ссылки для Google

На собственном домене будут доступны:

- Главная страница: `/`
- Политика конфиденциальности: `/privacy.html`
- Условия использования: `/terms.html`

Подключение Netlify само по себе не подтверждает приложение в Google. Домен отдельно подтверждается в Google Search Console; затем эти ссылки указываются в Google Auth Platform. Перед отправкой добавьте выбранную публичную почту поддержки.

## Локальная проверка

```sh
npm ci
npm run build
npm run check
npm test
npx netlify-cli dev --offline --dir docs
```

Откройте адрес, который напечатает Netlify. Локальные события сохраняются отдельно от рабочего сайта. Перед публикацией выполните проверки, затем отправьте изменения в `main` и дождитесь успешного Netlify deploy. Проверьте `/stats` и `/api/analytics`; ключи и личные данные в публичные файлы не добавляются.
